# Manuscript figures

`all_manuscript_figures.ipynb` is the single plotting notebook for experimental Figures 2–6 and Appendix Figures C1–C2. Figure 1 is an architecture schematic and is intentionally not included in the notebook. Open the notebook from the repository root, then run all cells after completing the experiments in [`../REPRODUCE.md`](../REPRODUCE.md). The notebook includes seven embedded preview outputs, so GitHub displays Figures 2–6 and C1–C2 immediately. Running the cells regenerates the plots locally from files produced under `../results/`.

Figures 2–6 and C1–C2 are regenerated by notebook code from experiment-produced files. Each figure cell exports PDF, SVG and PNG to `../results/generated_figures/`.

The repository contains no numeric result tables, plotting CSVs, checkpoints, or separate generated manuscript plot files. Only image previews embedded within the notebook are included. Original input data and a standalone synthetic-data example are retained; neither is a manuscript experiment result. Run the experiments and then all notebook cells to reproduce the manuscript plots.
