# Manuscript figures

`all_manuscript_figures.ipynb` is the single plotting notebook for experimental Figures 2–6 and Appendix Figures C1–C2. Figure 1 is an architecture schematic and is intentionally not included in the notebook. Open the notebook from the repository root, then run all cells after completing the experiments in [`../REPRODUCE.md`](../REPRODUCE.md). It contains saved display outputs so that the plotted panels are visible immediately on GitHub and in Jupyter. Re-execution refreshes those outputs from files generated locally under `../results/`.

Figures 2–6 and C1–C2 are regenerated by notebook code from experiment-produced files. Each figure cell exports PDF, SVG and PNG to `../results/generated_figures/`.

The current repository contains no separate numeric result tables, plotting CSVs, checkpoints, or generated manuscript plot files. Original input data and a standalone synthetic-data example are retained; neither is a manuscript experiment result. The notebook's saved display images are previews only; rerun the experiments and then all notebook cells to reproduce the manuscript plots.
