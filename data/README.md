# Data layout

The nonstationary synthetic dataset is generated by `common/synthetic_dataset.py`; no data file is required.

External datasets are not redistributed. Place author-downloaded files under `data/` using the paths expected by `common/datasets.py`:

- `EPA AirData/annual_conc_by_monitor_2025.csv`
- `LUCAS 2018 TopSoil Dataset/OriginalSoilDataset.csv`
- `California_Housing/fetch_california_housing.csv`

The loader documents the required columns. Consult the original providers for licensing, terms of use, and current download locations.

EPA rows sharing the same coordinates are retained as separate observations because their response records may differ. The reduced-observation experiment groups identical coordinates during splitting to prevent the same monitoring location from appearing in more than one partition.

Never commit restricted or third-party raw data to this repository.
